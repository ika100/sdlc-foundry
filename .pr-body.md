## Summary

**BREAKING (5.0).** The platform now speaks the domain model of ADR-053 (spec 114, ADR-054). A system is one file, `applications/<system>/system.yaml`, which `render.py` validates. It holds the components (with type and lang), APIs, resources (postgres, with `replicas`), the environments dev → staging → prod (with policy, promotion and observability) and the instances. Slash commands and `cplat` subcommands are grouped by noun: `system`, `component`, `api`, `resource`, `instance`, `issue` and `platform`. Every 4.x slash command is kept as a tombstone that names its replacement, and a 4.x `cplat` name exits 2 with its 5.0 form. Cluster names (namespaces, Argo applications, images, secrets) do not change. `cplat platform update --migrate` moves a 4.x gitops-app repo to `system.yaml`, but only when the 5.0 render is byte-identical to the frozen 4.7 renderer. The fleet merges a migration PR only when that proof holds.
