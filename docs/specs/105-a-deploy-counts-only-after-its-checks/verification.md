## Notes for spec 106 (reuse of `registry.digest`)

- Only the first 100 package versions are read (`registry.py:289`, `per_page=100`, no pagination). Older tags of an active package raise `RegistryError` ("not among the latest 100").
- The owner kind is guessed: `/users/...` first, then `/orgs/...`, so an org package costs two calls.
- There is only a tag → digest lookup. It has no digest → tags lookup and no batch form, so 106 would call `gh api` once per tag. A small `versions(image)` helper that returns the parsed list would make both cheap.
- Only `ghcr.io/<owner>/<name>` images are accepted. Use `registry.image_name(entry, slug)` to build the name; an explicit `image` in the entry is not lowercased.
