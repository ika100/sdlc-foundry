## Recording never fails a run, and the time bound

- **Never raises:** every mutator runs inside `try/except Exception` (`runs.py:296-307`, `runs.py:221-238`, `runs.py:249-264`). `finish` catches everything and prints only to stderr (`runs.py:413-443`, `runs.py:453-458`). `save_state` wraps `_record` (`ship.py:121-125`). `runs_store.gh` never raises (`runs_store.py:31-41`). `cplat runs begin/phase/end` always exit 0 (`runs.py:689-693`). The Stop hook's JSON on stdout is untouched.
- **Time:** by reading the code, `finish` measures from its own start, and `flush` gets what is left of 20 s (`runs.py:436`). The visibility call is at most 10 s, filings are retried only while at least 10 s are left, and each further `gh` call gets `min(10, remaining)`, with none starting below 1 s. That adds up to about 20 s plus process overhead. The file lock is held only for local reads and writes, never across network calls. As noted under AC-087.7, no test proves this bound.
- **No real GitHub in tests:** `conftest.py:18-24` unsets `CPLAT_RUNS_REPO`, `CPLAT_RUN_PARENT` and `CPLAT_HEADLESS` and points `CPLAT_RUNS_DIR` at a tmp dir, so `flush` stops at "unset" before `open_store`. Every test that sets `CPLAT_RUNS_REPO` also replaces `runs.open_store` (`test_runs.py:117-119`, `:471-475`). `test_runs_store.py` replaces `runs_store.gh` or `subprocess.run`. The headless subprocess test inherits the cleared environment. ✔
