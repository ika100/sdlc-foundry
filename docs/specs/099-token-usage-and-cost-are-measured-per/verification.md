## Observations (not blocking)

- A headless run owns its `claude -p` sessions, and a `ship` started inside such a session also claims the same session through `CLAUDE_CODE_SESSION_ID`. The same calls then appear in the `headless` record and in the `ship` record. The report groups by kind, so no kind is double-counted, but adding up across kinds would double-count. No criterion covers this.
- The sanitizer `^[A-Za-z0-9._:@/-]{1,80}$` would let through a secret with no `=` or space (for example a bare `ghp_…` token) if it showed up as a model id or agentType. Both fields are written by Claude Code, not taken from user content, so the risk is low.
