- **Go `deps.sh` runs `go get` a second time when `go mod tidy` drops the pin** (`service-go/scripts/deps.sh:36-41`). The design has only `go get && go mod tidy`. The extra step keeps the one `// indirect` require that AC-095.2 allows, for a module that is in the graph but not imported. The final check still fails (exit 1) below the target. Acceptable. No test covers this fallback, because the fixed fixture makes tidy keep the pin. A later `go mod tidy` in such a repo would remove the require again.
- **Python direct path uses `uv add --no-sync`.** The design has `uv add`. `--no-sync` skips the venv sync, so no file outside `pyproject.toml`/`uv.lock` changes, as the contract requires. Acceptable.
- **pnpm uses `pnpm install --no-frozen-lockfile` after writing the override.** The design has `pnpm install`. CI environments default to a frozen lockfile, which would refuse the override. Acceptable.
- Revert uses `git reset -q -- <files>` instead of `git restore --staged -- <files>` (`deps.py:195`). Same effect, and it is followed by a byte and diff self-check. Acceptable.
- `deps.py:141` reads the run pointer through `runs._read_pointer`/`runs._pointer`, which are private helpers of `runs.py`. This works and `runs.py` is unchanged, but it couples the two modules. Not a contract difference.
