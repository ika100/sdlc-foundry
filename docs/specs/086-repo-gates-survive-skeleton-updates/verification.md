## Deviations from the plan

1. **c63a47e changed the `drop` helper of `test_shape_check_rejects_a_workflow_without_the_ci_extra_check` after red** (so `cplat spec test-diff 71fde8d` exits 1). The original helper turned `${{` into `{{` and round-tripped service-go's un-rendered `ci.yml` through YAML. That cannot parse (`{{ … }}` is a flow mapping with a non-scalar key), so the test errored before it reached the contract. The new regex `^  ci-extra:\n(?:(?!  \S).*\n)*` removes the `ci-extra:` job header and every line indented deeper (or blank) up to the next two-space job key. It removes exactly the job and leaves the rest of the file byte-identical. The test name, AC tag, `new_errors` set difference and assertion are unchanged. It still proves that a workflow without the job yields `ci.yml has no ci-extra job running devbox run ci-extra`. **Acceptable**, and it does not weaken AC-086.5.
2. **`tests/cplat/test_ci_gates.py` (AC-075.1) `real()` passes `ci-extra` through.** `recipe(shape, "ci-extra")` would fail because no template defines it, by design. The test still asserts that `ci`'s chain equals the workflow's `devbox run` steps in job order, and now also covers that the `ci-extra` job sits in the right place. **Acceptable.** The file is in no task's `files`.
3. **Operand order of the devbox-install guard**: the code has `runner.environment == 'github-hosted' && steps.recipe.outputs.defined == 'true'`, the design has the reverse. `&&` on two side-effect-free comparisons is commutative, and the order satisfies the existing AC-064.2 test. **Acceptable.**
4. **t6 plugin and marketplace version bump not done**, which the user accepted: versions are bumped at release. **Acceptable.**
5. Files outside every task's `files`: `docs/adr/031-…md` and `docs/adr/README.md` (the plan says the ADR was written before the plan), `spec.md` (status `building`), and the tests (red commit and deviation 2). **Acceptable.**
