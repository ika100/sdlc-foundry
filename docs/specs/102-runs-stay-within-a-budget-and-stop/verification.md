## Normalisation as implemented (`budget.py:445-460`; spec 108 depends on it)

The text is the last 40 lines of the error. The steps run in this order:

1. ISO timestamps `YYYY-MM-DD[T ]HH:MM:SS[.frac][Z|±HH[:]MM]` are removed. A bare date (`2026-10-25`) stays.
2. Clock times `H:MM:SS[.frac]` are removed. `HH:MM` without seconds stays.
3. UUIDs become `<id>`.
4. Paths with at least one `/` (optionally `./`, `../` or `/` in front) become `<path>`. A bare file name such as `alerts_test.go` stays. Text like `and/or` and URL tails also becomes `<path>`.
5. Lowercase hex runs of 7 or more characters with at least one digit become `<id>`. Uppercase hex and letter-only hex (`deadbeef`) are not matched; any decimal number of 7 or more digits is.
6. `line N` (any case) becomes `line`.
7. `:N` or `:N:M` after a word character or `>` is removed.
8. Whitespace is collapsed.

Equivalent means the same stage key and the same `sha1(normalised)[:12]`. Progress means the failing count went down, or a name in the previous failing set is gone.

Differences from design.md: dates without a time, clock times without seconds and uppercase hex are not removed. Durations (`in 3.21s`) and short numbers (`#123`, `run 42`) are not removed either. Risk: pytest summaries (`2 failed in 3.21s`) differ on every run, so CI failures with a timing line are never equivalent.

## Correctness risks (no criterion, for the coder)

1. **The hook can block subagents.** Only exit 2 blocks, and a crash inside `budget` returns 70 (`cplat.py:116`), so that case is safe. But `cplat.py:99-101` returns **2** for an unknown command. A launcher that resolves to a platform without `budget` (`CPLAT_REF` or `CPLAT_PLATFORM` at a pre-102 checkout, or a stale marketplace checkout) blocks every Task and Agent call inside a run. `uv` also exits 2 on its own errors (no network or Python). Make the hook map every non-2 failure and these cases to 0, for example `cplat budget gate --invocation; rc=$?; [ $rc -eq 2 ] && exit 2 || exit 0` with a `budget` existence check, or have `gate` exit with another code.
2. **Idle time counts as minutes.** A ship resumed with the same `run_id` keeps `current.started_at` (`budget.py:192-193`). A `runs begin build` after an interrupted session finishes the old run as `abandoned` with its wall clock up to now carried (`budget.py:389`, `runs.py:943`). A run interrupted overnight is then `budget exhausted: minutes` at the first safe point.
3. **Ledgers that never close.** Only an outcome of `done` closes a ledger, and nothing prunes `budgets/`. An abandoned spec keeps an `open` ledger whose usage returns months later. A remote that is not on GitHub falls back to the directory name (`runs.py:113`), so two repos with the same name and spec id share a ledger.
4. **Cost at the subagent hook.** `check` reads transcripts on every Task or Agent call (`budget_s=3.0` per record, `budget.py:221`). Fine within the 30 s hook timeout, but it is the per-call read the design ruled out ("Cost is read only at safe points, never per call"; the hook is a safe point, so this is a note only).
