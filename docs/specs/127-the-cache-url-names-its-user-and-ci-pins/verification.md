## Observations (not blocking)

1. **Gaps in the check-pins part 4 guard** (`scripts/check-pins.py:282`). The guard does not catch two cases:
   - A versioned flag next to the file, such as `--with pytest==9.3.0` or `--with 'pytest>=9'`. The regex needs whitespace, a quote or the end of the line after the package name.
   - A suite command split over continuation lines, because only a line containing `pytest tests/cplat` is checked.

   Neither case can install a tool outside the pins while `--with-requirements requirements-test.txt` is present: uv resolves against the `==` pins and fails on a conflict. The criterion's case (a command without the file) is caught. Possible later fix: also match `[=<>!~]` after the name.
2. `.github/workflows/ci.yml:111` still installs `pyyaml` unpinned for `check-pins.py` itself. This is not the cplat suite and is outside AC-127.5, but it is the last unpinned test-time tool in the platform's CI.
