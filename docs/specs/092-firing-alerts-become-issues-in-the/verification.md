## Non-goals

There is no in-cluster bridge (webhook receiver or contact point), no paging or chat output, no `PrometheusRule` CRD, and no Alertmanager install. Alertmanager is only read, at `alertsources.py:349-351`. Nothing is written to the run store: `alertissues.reconcile` does not call `autoissue.file()`, as `alertissues.py:5-6` says. Nothing is built from an issue automatically. `local-cluster.sh` only exposes the existing lgtm Prometheus port 9090. ✔

## Deviations from the plan

- **`tests/cplat/test_ci_templates.py:113`** (AC-064.1 harness). A bare `runs-on: ${{ vars.CI_RUNNER }}` is now accepted, but only when the same workflow also has `if: vars.CI_RUNNER != ''`. AC-092.3 needs exactly this: the job must never fall back to a hosted runner. Without the change, the AC-064.1 test would demand the hosted fallback that AC-092.3 forbids. Acceptable. One weakness: the `if:` check looks at the whole file, not the job. That is harmless here because `alerts.yml` has one job, and `test_alerts_template.py::test_the_poll_never_runs_on_a_github_hosted_runner` checks the job itself.
- **`tests/cplat/conftest.py:53-58`**. The autouse fixture only clears the `ALERTS_*` and `GITHUB_STEP_SUMMARY` environment variables. The plan said to replace the seams `tracker`, `http_get` and `kubectl`. This is acceptable: two red tests exercise the real defaults with a stubbed transport (`test_the_default_http_get_and_kubectl_never_raise`, `test_the_default_tracker_writes_other_repos_with_alerts_token`). The other tests replace the seams themselves through `alerts_fakes.py`.
- **`docs/adr/038-alert-poll-on-the-gitops-runner.md` and `docs/adr/README.md`**. Neither is in any task's `files`. The ADR was renumbered from 036 to 038 after a merge collision. Acceptable. Non-blocking leftover: the module docstrings still say "ADR 036" (`scripts/cplat/alerts.py:1`, `scripts/cplat/alertsources.py:1`, `scripts/cplat/alertissues.py:1`) and should say ADR-038.
- **`tests/cplat/alerts_fakes.py`** and the new test modules come from the red-test commit 79e8bab. Expected.
