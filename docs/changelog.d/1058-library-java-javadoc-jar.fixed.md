**The `library-java` template publishes a javadoc jar (#1058).** A release deployed only the jar and the sources jar, so consumers' IDEs showed no API docs. The build now attaches `<artifact>-<version>-javadoc.jar` (maven-javadoc-plugin, `doclint` without the missing-comment check, warnings fail the build), so `devbox run test` and `ci` fail on a broken javadoc before a tag, and the publish dry run lists it. Existing libraries: add the `maven-javadoc-plugin` block with its `attach-javadocs` execution and the `javadoc.plugin.version` property from the template's `pom.xml`.
