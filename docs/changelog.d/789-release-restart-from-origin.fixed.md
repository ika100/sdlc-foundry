**A restarted platform release builds on origin/main (#789).** Releasing 5.23.3 took three starts: the second reused the never-pushed release branch of the first, made from an older `main`, and the third stopped because the local `main` was behind. `cplat platform release` now branches from `origin/main`, starts a never-pushed release branch that is behind `origin/main` again, and stops only when the local `main` has commits that are not on `origin/main`. After a merge from a linked worktree, `cplat pr wait --merge` and the ship's land leave that worktree detached at `origin/main` instead of switching it to `main`, so `main` stays free for the main checkout.
