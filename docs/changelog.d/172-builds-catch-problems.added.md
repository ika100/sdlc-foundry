**A build catches test and sign-off problems before the pull request (spec 172).** `cplat spec test-diff` now judges only the frozen red-tests files, so later tests in the same directory no longer trip it. `devbox run test-fast` takes arguments (`cplat quiet test-fast -- <args>`, also `--repeat`), and `cplat component build tests <spec> <task>` prints the tests of one task, so a coder runs only its own tests while the whole suite runs at build step 2.5 and in Phase 3. A new build step 2.6, the load run, runs the spec's new tests three times at once before Phase 3; a failure that does not repeat goes to the tester as a harness problem. In the platform repo `cplat component build merge` refuses a task branch with an unsigned commit, and `cplat platform rules check` reports a `hidden-rule` finding for a rule hidden in a prompt without a register entry. See [ADR-094](../adr/094-a-build-runs-each-coder-on-its-own-tests-and-new-tests-under-load.md). Update the plugins (`/plugin marketplace update`).
