**An unattended run checks its refused rules before the first session (spec 206).** In week 2026-W46 five runs and three environment escalations ended "no progress after two sessions without a commit", over six hours of run time, because a refused rule (`gh api *merge*`) also matched a read-only `gh api` query of a pull request's `mergeable` state, and the session could not do ordinary work. `cplat headless` now checks the refused rules against a fixed sample of commands the run needs and commands it must never run, and stops before any session with `preflight failed: deny-rules: …` and the corrected rule (`use: …`) or the missing rule (`add: …`). The `gh api` rule is narrowed to the merge endpoints, so reading `mergeable` or `mergeStateStatus` is no longer refused.
