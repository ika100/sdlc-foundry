**An attended system ship asks a repo's decision at once, while the other repos keep running (#986).** A repo whose ship escalated with a question it could not settle from a suggested answer was held until the whole run escalated, so in journey 26 the person was asked an hour after the web repo stopped, and its work then ran serially. Now `cplat system ship next` names in `do` what the coordinator does with the repo: `resume` with the suggested answers, `ask` the person now when the session is the person's own, or `hold`. On `ask` the coordinator asks with AskUserQuestion and resumes the repo on the reply; the other repos run on in their own sessions. Unattended runs (`cplat headless`, the supervisor) still hold the repo until the run escalates as a whole ([spec 186](../specs/186-the-journey-waits-less/spec.md), AC-186.12). Update the plugins (`/plugin marketplace update`).
