**One prod promotion carries a release of several components (#505).** `--version vX.Y.Z` took one component per call, so a release of two components gave two prod PRs that conflicted on `system.yaml` and the ApplicationSet. `/instance:promote --to prod --version api=v0.1.0,web=v0.1.0` now pins each component to its version in one PR; named components (or `--all`) without a version still take their newest release, and `--version vX.Y.Z` for one component works as before. Update the plugins (`/plugin marketplace update`).
