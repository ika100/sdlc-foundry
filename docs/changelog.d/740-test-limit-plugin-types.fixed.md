**A new Python service passes its own type check again (#740).** The per-test limit plugin that 5.22.0 adds to the service-python and library-python templates had no type annotations, so a fresh repo's strict `mypy .` failed and its first image was never published. The plugin is annotated now, and the platform's template check runs the same `mypy .` as the generated repo instead of only `mypy src`. Run `/platform:update` in a repo created from 5.22.0.
