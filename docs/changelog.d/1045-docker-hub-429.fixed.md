**The e2e and smoke image builds no longer fail on a Docker Hub rate limit (#1045).** Every job that builds images logs in to Docker Hub when the repository secrets `DOCKERHUB_USERNAME` and `DOCKERHUB_TOKEN` are set (one pinned `docker/login-action`); without them (forks, a repo without the secrets) the step is skipped and the build runs anonymously as before. The e2e scripts build through `e2e_docker_build` (`tests/e2e/lib/docker-build.sh`), which retries once after a `429` in the build output. The owner adds the two secrets.
