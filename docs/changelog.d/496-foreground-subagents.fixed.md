**Coordinators wait for their subagents without polling, and a working background agent is progress (#496).** Ship and build coordinators waited for background subagents with hand-written shell loops on output files, git HEAD or docker images, and ended turns while an agent still ran, so the Stop hook counted stops without progress and escalated the run. `/component:build`, `/component:ship`, `/component:plan`, `/component:fix`, `/component:release` and `/system:ship` now launch subagents in the foreground (`run_in_background: false`, parallel ones as several Agent calls in one message) and never poll for them. The Stop hooks of `/component:ship` and `/system:ship` let a session stop while one of its background subagents still works and do not count that stop. Update the plugins (`/plugin marketplace update`).
