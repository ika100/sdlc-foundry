**The red check no longer counts a missing third-party package as missing behaviour (#956).** `cplat quiet test-fast --red` classed every `ModuleNotFoundError` from outside the tests as `missing behaviour`, so in journey 25 44 acceptance tests that never imported (`testcontainers` was not installed yet) passed the red gate and froze. Now an import error is `missing behaviour` only when it names the repo's own code (the project's package, or a module or package under the root or `src/`); any other is a `test error`, and a package that cannot be found at all gets the line `<pkg> is not installed: add it to the dev dependencies`, which goes back to the tester. A red test for a brand-new top-level package needs that package to exist first ([spec 205](../specs/205-acceptance-tests-are-proven-passable/spec.md), AC-205.5).
