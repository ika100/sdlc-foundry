**A backup to a bucket that does not exist yet is one pull request (#860).** `cplat resource backup <db> --env <env> --to <bucket>` refused a bucket that was not declared, so the session opened a bucket PR first and the backup PR only after its merge; auto mode refused to merge the bucket PR the person never asked for, and prod went live without a backup. A `--to` name that is not a resource yet is now declared as an in-cluster bucket (10Gi, like `resource add <name> --type bucket`) in the same change; the preview says so. A name that is another resource, a component or not a valid resource name is still refused. Update the plugins (`/plugin marketplace update`).
