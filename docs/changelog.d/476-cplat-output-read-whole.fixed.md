**Agents read `cplat`'s output whole instead of filtering it with `grep` (#476).** An agent ran `cplat instance verify dev 2>&1 | grep -E 'smoke:|Smoke|FAIL'`; the filter hid the `Promotion (staging)` line, the decision whether staging follows the build, so it stayed unclear why staging had not moved and it was promoted by hand. Every command and agent that calls `cplat`, and the subagent prompt of `/system:ship`, now says to read its output whole, never through `grep`, `head` or `tail` (its last lines carry the decisions, next steps and fixes), and to use `--json` where a command offers it; a test fails when a command, agent or reference text pipes a `cplat` call into one of them. Update the plugins (`/plugin marketplace update`).
