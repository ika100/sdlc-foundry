**Parallel ships no longer stop each other, and the usage limit pauses a run instead of failing it (#184).** Runs in several worktrees used to collide on one ship slot, a usage limit ended a run as a failure, and a land stopped when another PR took the same ADR number or rule number. Now `cplat headless` takes a slot from a per-repo pool (`slots` in `.platform/dispatch.yml`, shared with the dispatcher and every worktree), prints `waiting for a slot: held by …` or, with `--no-wait`, exits 1 with `slot busy: held by …`, and frees a stale slot with `freed a stale slot of …`. A session that hits the usage limit pauses the run (`paused: usage limit, next try at <time>`, 5 to 60 minutes between tries) and after 360 minutes in total exits 1 with `environment pause: usage limit resets at <time or "unknown">`, recorded as escalated with cause `environment`; running the same command again continues. The land renumbers a clashing ADR and rule register entry (`renumbered ADR-<old> to ADR-<n> …`) and reads CI logs on its allowlist. `devbox run ci` lints changed templates and reports file, line and rule, and env-prefixed devbox commands in a plan are allowed verbatim. See [the guide](../unattended-delivery.md). Update the plugins (`/plugin marketplace update`).
