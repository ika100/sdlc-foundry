**The `library-typescript` template ships source maps that carry their sources (#967).** The package publishes only `dist`, but its maps pointed at `src/` files a consumer does not have. The build now sets `inlineSources` and drops `declarationMap` (a declaration map cannot inline sources). Existing libraries: add `"inlineSources": true` to `tsconfig.build.json` and remove `declarationMap`.
