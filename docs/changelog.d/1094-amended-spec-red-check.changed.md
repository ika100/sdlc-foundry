**The red check of an amended spec judges only the tests of its new or changed criteria (#1094).** When a spec was amended after it was built, the red check of build Phase 1 sent the passing tests of the built criteria back to the tester as `passes`, so the build could not freeze the tests of the amendment without a person. Now `cplat component build tests <id> --red` adds `--spec <id>` for a spec whose Changelog has an `amended` line after a `done` line, and `cplat quiet test-fast --red --spec <id> -- <files>` judges only the tests that trace to a criterion new or changed since the spec's last `done` commit. Every other test must pass and prints `passes (not judged: <ids> unchanged)`; one that fails prints `regression`, and the build escalates with cause `code` before any coder runs. A spec built for the first time is checked as before ([ADR-131](../adr/131-an-amended-spec-judges-only-the-tests-of-its-changed-criteria.md), [spec 205](../specs/205-acceptance-tests-are-proven-passable/spec.md)). Update the plugins (`/plugin marketplace update`).
