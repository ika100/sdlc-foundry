**A `git push` that GitHub refuses for a transient reason is retried instead of escalating the ship (#500).** A push rejected with `remote rejected … fatal error in commit_refs_rules`, a 5xx (`RPC failed; HTTP 502`), a dropped or refused connection or an unresolved host used to fail at once, and an unattended ship stopped until a person said "retry". Every push of cplat (ship, system ship, fleet, spec PRs, releases, gitops PRs) now backs off (15 s, doubling to 2 min) and pushes again for up to 8 minutes before it fails with the last error; any other refusal (non-fast-forward, protected branch, permission) still fails at once. Update the plugins (`/plugin marketplace update`).
