**The land resolves conflicting plugin versions itself (#1075).** A pull request that bumped a plugin version in `plugin.json` and `marketplace.json` while `main` bumped it too was held as "rebase is a human decision". The land now takes the higher version (one patch above main's when the branch's is not higher), merges the rest of the file as text, and still hands any other conflict to a person; ADR index rows and `docs/backlog.md` were already resolved this way.
