**The service-typescript image has a size budget the platform CI checks (#968).** The template already loads only the OpenTelemetry instrumentations it uses (http, fastify, pg, pino) instead of the auto-instrumentations bundle; the `smoke-test-service-typescript` job now measures the unpacked filesystem of every variant with `docker export | wc -c` and fails above 250,000,000 bytes, so a larger base image or an instrumentation bundle cannot slip in.
