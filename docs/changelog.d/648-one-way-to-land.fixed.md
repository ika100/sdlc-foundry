**Every merge into `main` takes one land path with a stated mode (#648).** A release whose branch fell behind `main` used to catch up silently; it now pushes and merges nothing and stops with `main moved: start the release again` and a `fix:` line (close the release PR, delete the release branch, run `cplat platform release`). The other land commands update the branch and wait for the new head's checks before merging, and a refused merge goes back to waiting, at most 3 times, then stops with `merge refused 3 times: <reason>`. Tests in `tests/cplat` wait for events through `tests/cplat/waiting.py` instead of fixed sleeps, and `scripts/check-test-sleeps.py` checks it ([ADR-100](../adr/100-every-merge-into-main-takes-one-land-path-with-a-stated-mode.md), [ADR-097](../adr/097-tests-wait-for-events-never-for-a-fixed-time.md)).
