**Release evidence and backup reports stay true during a network outage (#792).** A staging smoke whose run record is still in the local buffer, because the run store was unreachable at upload, now counts as evidence ("on this machine, not uploaded yet"). When the run store cannot be read, the release says the smoke "could not be checked" instead of reporting it missing. A failed backup whose WAL archiving also fails names the bucket as the likely cause and the `kubectl get pods` command to check it.
