**`cplat pr wait` no longer fails on a run cancelled by concurrency when another run of the same commit passed (#510).** `gh pr create --label` starts two runs of one workflow for the same commit (`opened` and `labeled`); when concurrency cancelled the newer one, the wait judged that cancelled run and stopped with "a required job failed or was cancelled" although the other run was green. Per workflow and head commit the wait now judges the newest run that was not cancelled (the run list's conclusion, else its checks); a cancelled run that no other run of its workflow replaces is rerun once (as a stuck run, spec 079) and is red only when it is cancelled again. Update the plugins (`/plugin marketplace update`).
