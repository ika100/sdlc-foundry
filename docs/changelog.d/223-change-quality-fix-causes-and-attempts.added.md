**Change quality: fix causes and attempts to done (spec 223).** A `fixed` fragment now ends in a checked `Caused by: #<PR> | v<X.Y.Z> | none | unknown` line (`cplat platform pr-check` verifies it on GitHub, CI checks the form), `cplat platform change-quality [--since vX.Y.Z] [--json]` reports per release the fixes it caused, their blast radius and the change-failure rate, and the `Chains:` block of `cplat platform runs report` groups ship, build and fix runs into chains with attempts to done and chain cost ([spec](../specs/223-change-quality-fix-causes-and-attempts/spec.md)).
