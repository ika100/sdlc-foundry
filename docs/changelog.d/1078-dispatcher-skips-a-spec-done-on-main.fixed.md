**The dispatcher no longer starts, or keeps holding, a spec that another session already shipped (#1078).** A spec merged elsewhere after the backlog snapshot was read still got a ship unit, which reset its branch to `origin/main` and was held as `needs-decision`. Before a ship start the dispatcher now fetches `origin/main` and skips a spec whose status there is `done`, and each cycle clears the hold of a spec that is no longer draft, approved or building on main.
