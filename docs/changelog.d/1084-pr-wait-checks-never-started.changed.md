**`cplat pr wait` tells checks that never started apart from failures (#1084).** When GitHub Actions cannot start (a billing or spending-limit block on a free private repo), every check reports a failure without having run, and nothing stops a manual merge. The wait now ends with `NOT RUN: … never started` instead of `RED`, records the result `not-started`, and points to `devbox run ci` as the local merge gate. A run in which any check did start is still red.
