**A docs-only land no longer waits for a code PR's catch-up e2e, and a green e2e is kept when `main` moved only outside its scope (#1068).** Docs PRs waited about 35 minutes behind a code PR that held the merge lock through its cluster e2e after an update-branch, and lock waits reached 26 minutes. Now a land inside the e2e scope releases the lock's flock under a catch-up claim while its checks run, so lands outside the e2e scope merge in a fast lane; in-scope and release lands still queue. When the commits that arrived since the last green e2e are all outside the e2e scope, the land keeps that e2e and cancels the new head's e2e runs after the merge. Every land records its lock and catch-up waits, and `cplat platform runs report` shows the median and p90 per docs and code lands ([ADR-089](../adr/089-every-merge-into-main-holds-the-repo-merge-lock.md), [spec 220](../specs/220-a-docs-only-land-does-not-wait-for-a/spec.md)).
