**`cplat pr wait` no longer waits an hour on a queued check run of another app (#1052).** Dependabot's `.github/dependabot.yml` check can sit `queued` with a check run that never starts, and its suite cannot be re-requested, so a PR with all CI green timed out unmerged (#999 skipped only suites without check runs). A pending check that no Actions run backs, while the head shows a suite of another app that is still `queued`, is now printed once as "not waited for". A started foreign check is still waited for.
