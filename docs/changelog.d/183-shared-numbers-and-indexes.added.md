**Shared numbers and indexes now come from cplat (#659, #660, #477, #577).** `cplat spec new` takes one more than the highest spec number on main, every pushed branch and every open PR, and `cplat spec check` reports a spec or ADR number that this branch and another branch or PR both add. `cplat adr add <slug> --decision "<one line>"` writes the next ADR from the platform's template and appends exactly one row to the ADR index, so the architect no longer numbers ADRs or edits the index by hand. A criterion that changes another spec's active criterion ends with `(replaces AC-<NNN>.<n>)`; the old one is struck through as `superseded by`, counts as withdrawn in trace, verify and the done count, and `cplat spec check` refuses an unstruck target (`cplat spec new --from-plan` strikes it for a system plan's slice). A cplat command whose output pipe is closed (`cplat … | head -1`) exits 141 without a traceback and no longer files a crash issue. See [ADR-099](../adr/099-shared-numbers-and-indexes-are-handed-out-by-cplat.md) and [spec 183](../specs/183-shared-numbers-and-indexes-come-from/spec.md).
