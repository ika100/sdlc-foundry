**The web template's local end-to-end tests no longer need port 3000 (#479).** `devbox run e2e` started the app on the fixed app port, so the tests failed while another local process (a container, a dev server) held it. `playwright.config.ts` now starts the app on `E2E_PORT`, else `PORT`, else a free port it picks, and uses the same port for the server and the tests' base URL; `next start`, `pnpm dev` and the container keep the app port. Existing web repos get the change with `/platform:update`.
