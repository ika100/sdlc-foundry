**The secrets scan no longer flags the plan contract files (#958).** `contract/<plan>.json`, which the platform writes, holds the 40-character commit sha of the plan, and detect-secrets reported it as a secret. The `secrets-scan` recipe of every template that ships a detect-secrets config now excludes `contract/*.json`, and so does the pre-commit hook of the Python templates. Update the repo (`/platform:update`) to get the exclusion.
