**The Java jobs in platform CI restore the Maven repository from the Actions cache (#1054).** Maven Central answered `429 Too Many Requests` to parallel Java jobs, and each one turned a PR red until it was rerun. The service-java, library-java and upgrade jobs now use `setup-java` with `cache: maven`, keyed on the template `pom.xml.jinja` files, so a PR reads few artifacts from Central; the retry handler stays.
