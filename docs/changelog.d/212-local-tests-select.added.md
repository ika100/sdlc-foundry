**Local runs of the platform's own tests run only what a change can affect (spec 212).** A full local run of the cplat tests takes about 8 minutes, and a platform build ran it several times after small changes. `devbox run test-fast` without arguments and `scripts/ci-local.sh` now run only the test files the change can reach, read from a dependency map that the last full local run recorded: what each test file imported, opened, listed or handed to a subprocess, also inside the cplat processes it started, and through shared fixtures and renders. Without a map, after a change to the suite's setup, for changed code no test reads, or when the change reaches more than half of the test files, they run everything and say why. `devbox run test-fast --full`, `devbox run test` and `ci-local.sh --full` run every test; CI is unchanged and runs every test on every pull request ([ADR-123](../adr/123-local-test-runs-select-by-recorded-dependencies.md), [spec 212](../specs/212-local-tests-run-what-a-change-can-affect/spec.md)).
