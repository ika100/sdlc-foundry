**A scoped test run runs only its targets (#502).** `cplat validate` runs the tests of a change as `devbox run test-fast -- <test files>`, but devbox passes those files to a recipe as `$1…$n` and the `test` and `test-fast` recipes did not forward them, so every scoped run quietly ran the whole suite (correct, but slower). The recipes of all five component templates now end with `"$@"`; the Python recipes no longer name `tests/` (without arguments pytest runs the `testpaths` of `pyproject.toml`, so a run without targets still runs the whole suite, `test` with coverage). For `service-go` and `service-java` extra arguments reach `go test` and `mvn` as flags. Existing repos get the change with `/platform:update`.
