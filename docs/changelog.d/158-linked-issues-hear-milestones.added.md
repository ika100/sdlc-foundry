**Linked issues hear when their spec, PR and release land (#568).** `cplat` now posts one comment on each issue a spec tracks or a PR closes when the spec is written and approved, when the PR merges and when a release ships it, without asking per comment; it still never files an issue itself. A hidden marker line keeps a re-run from posting twice, a failing or slow `gh` only prints a `note:` line, and `/component:release` closes the linked issues with one call, `cplat component release issues --version vX.Y.Z`. The closing note of every command names milestone comments next to `platform` escalations ([ADR-122](../adr/122-milestone-comments-on-linked-issues-need-no-per-comment-ok.md)). Update the plugins (`/plugin marketplace update`).
