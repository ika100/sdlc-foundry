**Inline scripts add no uv environment per worktree (spec 209).** `uv run` keyed its environment by the script path, so every worktree of a repo added one more environment under `~/.cache/uv`. `cplat`, the platform's own recipes and the `gitops-app` and `cluster-gitops` recipes now run inline scripts through `scripts/uv-script.sh`, which keys uv's environment by the dependency list; cplat uses it for the scripts of a target repo too. The `gitops-app` template gains a `plan` recipe that the system prompts call. `/platform:update` brings the change to existing repos with no step by hand.
