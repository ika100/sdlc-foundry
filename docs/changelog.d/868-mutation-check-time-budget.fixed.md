**The report-only mutation check keeps to a 90 s budget (#868).** `cplat spec mutate` ran up to 20 mutants one after another, each paying the devbox start and the test setup, and took 341 s in a journey's verification. The whole check (the baseline run included) now keeps to a wall-clock budget, 90 s by default (`--budget SECONDS`): no run outlasts what is left, and when the budget runs out the check stops, restores the files and reports a partial score over the tested mutants ("5 of 20 mutants tested in 90 s (time budget)") in `verification.md`, still with exit code 0. A run cut off by the budget counts as untested, not as caught. Mutants still run one at a time: parallel copies of the tree would each need their own devbox environment and venv and would share services such as a local Postgres.
