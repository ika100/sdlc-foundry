**The first image of a new component reaches GHCR even when the two architecture builds race (#866).** The first `main` build of a new repo pushes a new GHCR package from the amd64 and arm64 jobs at once, and one of them could fail with `denied`, so no image and no dev pin came and the deploy waited for nothing. A publishing build now retries a failed build-and-push once after 20 s (a cached build of a few seconds), in the service-python, service-go, service-java and web-nextjs templates. **Action:** existing repos get it with `/platform:update`.
