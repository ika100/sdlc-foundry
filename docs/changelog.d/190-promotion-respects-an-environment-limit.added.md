**Promotion respects an environment limit in the spec (spec 190).** A spec can list `environments: [dev]` in its front matter; `cplat spec check` validates it, `cplat spec show` and `cplat spec approve` print it as `Environment limit: …`, and while the spec is `building` or `done`, `cplat instance promote --to staging|prod` refuses with `environment limit: <spec_id> allows <envs>, not <target>` (the dry run lists `REFUSED:` lines) and automatic staging promotion skips with `not promoted: environment limit <spec_id> allows <envs>` instead of going red. Only a person overrides it, with `--accept-environment-limit "<reason>"`, recorded in the output and the PR body; the product-manager no longer suggests a limit the request did not ask for. Update the plugins (`/plugin marketplace update`).
