**The dispatcher keeps its platform checkout current and shows where it stands (#1074).** Units ran on the platform checkout the dispatcher was started in, so fixes merged to `main` later (for example the red-check fix #1051) never reached them and the units kept failing with the old bug. `cplat dispatch status` now shows a `platform:` line with the commit the units run on and how many commits it is behind `origin/main`; before each unit starts, the dispatcher fetches and moves a clean, detached platform checkout to `origin/main`. A dirty or branch checkout is left alone, and `status` and any escalation name it and how far it is behind.
