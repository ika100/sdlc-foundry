**The Python templates' lint gate no longer trusts a stale ruff cache (#495).** In a service repo the local `devbox run quality` passed while the first CI run failed on an import-order error (I001): a stale `.ruff_cache` hid it locally. The `lint` recipe of `service-python` and `library-python` now runs `ruff check --no-cache` and `ruff format --no-cache --check`, so the local gate sees what CI sees. Existing Python repos get the change with `/platform:update`.
