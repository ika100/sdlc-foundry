**A `starter` plugin installs the starter set, and every plugin brings the `shared` plugin it needs (#644).** `/plugin install starter@sdlc-foundry` installs `shared`, `system`, `component` and `platform` in one step; each plugin installed alone brings `shared` with it. This needs Claude Code 2.1.311 or later. An existing installation needs only `/plugin marketplace update` followed by a plugin update (`claude plugin update <name>@sdlc-foundry`). See [ADR-095](../adr/095-plugins-declare-dependencies-and-starter-bundles-the-set.md).
