**A spec number steers the spec, and a ship PR closes the spec's issues (#638, #645).** The dispatcher read a bare number as an issue and could act on the wrong item: it now reads a spec number as the spec and `#N` or `issue-N` as the issue, refuses an ambiguous number and prints what it acted on. `cplat component ship pr` left `{{CLOSES}}` in the body, so a ship PR did not close the issues the spec tracks: it now fills the closing lines like `cplat pr open --spec` and exits 2 before CI and the push when the body would still contain the placeholder.
