**`operator-lgtm` stays Synced in Argo CD (#508).** The Grafana route in `operators/lgtm/route.yaml` left out the fields the Gateway API CRD defaults (`group` and `kind` of the parent and backend references, the backend `weight`, the rule's `PathPrefix /` match); the API server filled them in, and Argo CD's client-side diff compared the route's lists as a whole and reported the application OutOfSync while Healthy. The route now writes every default out, `cluster-up` applies the same object, and the application uses the server-side diff like every other operator application (#307). Existing gitops repos get it with `/platform:update` and a re-render.
