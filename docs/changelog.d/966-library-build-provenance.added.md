- The four library templates (`library-python`, `library-typescript`, `library-java`, `library-dotnet`) attest the build provenance of the published files: the `publish` job gets `id-token: write` and `attestations: write` (still the only job with write permissions, ADR-125) and runs `actions/attest-build-provenance` (pinned) on the wheel and source archive, the npm tarball, the jar or the nupkg. `scripts/shapes.py check` verifies both. GitHub Packages' npm registry does not accept `npm publish --provenance`, so the tarball is attested by the action. Attestations of private repos need GitHub Enterprise (ADR-019); the attest step fails there until the repo is public. (#966)
