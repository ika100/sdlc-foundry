**`cplat quiet test-fast` says so when it gives up with no test running (#797).** When every test had ended and the run still blocked, the give-up block ended after its first line and named nothing. It now adds `still running: no test (every test ended; the run blocks after the last one)`. A full run on a loaded machine can take over the 9-minute limit (one run took 9 min 24 s with all 11160 tests passing); the limit itself is fixed by spec 185 (A4).
