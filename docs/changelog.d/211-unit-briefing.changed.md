**Unit sessions start from a briefing and spend fewer calls on bookkeeping (#869).** A third of the calls in a unit session went to reading the build instructions and recording phases and gates. `cplat component ship start <spec> --unit <unit>` and `cplat component ship unit` now print the unit's own instructions, cut from the build instructions by heading ([ADR-128](../adr/128-unit-briefings-are-cut-from-the-build-instructions.md), [spec 211](../specs/211-unit-sessions-start-with-their/spec.md)). `cplat quiet ci` records the gate and the ci stage of the build run, `cplat spec test-diff` finds its base without `--base`, and the build markers are set by the commands that start each phase, so the prompts no longer call them. Interactive runs are unchanged. Update the plugins (`/plugin marketplace update`).
