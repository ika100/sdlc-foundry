**`cplat dispatch resume <spec>` removes the `needs-decision` label its own escalation put on the spec's tracked issues (#1073).** Before, the verb found the issues only through the spec's worktree unit and printed `resumed: spec …` while the spec stayed `held: needs-decision`, and the label came back with each escalation. Now it finds the issues through every unit of the spec and the spec's `tracks`, removes the label where the dispatcher's escalation comment is on the issue, and prints `still held: spec …: #N …` with the reason (exit 1) when a label a person set stays or the removal fails.
