**An on-demand backup waits until its last WAL segment is archived (#793).** On an idle database `cplat resource backup` completed while its last WAL segment still waited on the server, and a restore right after failed with "WAL ends before end of online backup". The backup now closes that segment and waits up to 2 minutes for it to be archived; if it is still not archived it says so, because a restore to the backup fails until it is.
