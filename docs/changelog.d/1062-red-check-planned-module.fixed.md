**The red check no longer calls a module that the plan creates "not installed" (#1062).** A missing module is now the repo's own code (missing behaviour) when a `files:` entry of the plan of the spec in build names it (`scripts/cplat/<new>.py`, `src/<pkg>/…`), and a module that already sits in an in-repo `sys.path` directory of the test run (the plugin records them at start) counts too. A third-party name stays a test error with the "not installed" line (#956). Platform specs that add a module in `scripts/cplat` no longer escalate in red-tests.
