**The service-dotnet image has a size budget the platform CI checks (#1057).** The reported 187 MB was the local Docker image store's figure; the image's filesystem is about 133 MB on amd64 (141 MB on arm64) and about 60 MB to pull, of which the chiseled ASP.NET Core base image is about 125 MB. The template no longer publishes the IIS `web.config` or the API documentation file, and the `smoke-test-service-dotnet` job now fails any variant whose unpacked filesystem exceeds 150,000,000 bytes, so a larger base image or a self-contained runtime copy cannot slip in. Trimming stays off: a trimmed self-contained publish is about 50 MB but reports over 100 trim warnings from EF Core, Npgsql and the shared framework ([ADR-127](../adr/127-service-dotnet-stack.md)).
