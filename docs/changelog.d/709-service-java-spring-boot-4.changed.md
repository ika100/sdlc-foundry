**The `service-java` template renders Spring Boot 4.x on the distroless debian13 runtime (#709).** New repos get Spring Boot 4 and `gcr.io/distroless/java21-debian13`, the four CRITICAL findings of the previous stack are gone and no longer on the accepted list ([ADR-009](../adr/009-service-java-stack.md), [spec 204](../specs/204-service-java-on-spring-boot-4-cve-free/spec.md)). Existing repos get the new runtime base image with `/platform:update` and keep their project-owned Spring Boot 3 build (and its spring-webmvc findings) until they migrate. **Action:** to move an existing repo to Spring Boot 4 by hand: set the parent to 4.x; drop the `tomcat.version` and `jackson-bom.version` overrides; replace `spring-boot-starter-web` with `spring-boot-starter-webmvc` and add `spring-boot-starter-webmvc-test`; import `@AutoConfigureMockMvc` from `org.springframework.boot.webmvc.test.autoconfigure` and replace `@AutoConfigureObservability` with `@AutoConfigureMetrics`; with a database, use `spring-boot-starter-flyway`, the Testcontainers 2 artifacts (`testcontainers-junit-jupiter`, `testcontainers-postgresql`) and the package `org.testcontainers.postgresql.PostgreSQLContainer`; move your own Jackson code to `tools.jackson`; remove CVE-2026-47884 from `.trivyignore`. Update the plugins (`/plugin marketplace update`).
