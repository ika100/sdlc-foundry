**`cplat deps patch` works in a fresh repo (#502).** The `deps-findings` and `deps-bump` recipes of every template dropped their arguments: devbox passes them to a recipe as `$1…$n`, and the recipes did not forward them, so `scripts/deps.sh` printed its usage, and `cplat deps` reported a devbox error with the hint to run `/platform:update`, even in a repo created minutes before. The recipes (and the `migrate-new` recipe of `service-python`) now forward `"$@"`, and a failing `deps-findings` reports the recipe's own last line instead of devbox's wrapper line, without the update hint. Existing repos get the change with `/platform:update`.
