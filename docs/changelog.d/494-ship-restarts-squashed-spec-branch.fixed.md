**A ship no longer builds on the squash-merged spec branch (#494).** `gh pr merge --squash --delete-branch` deletes the spec branch on GitHub and in the clone but leaves the stale remote-tracking ref `origin/feature/<spec>`, so `cplat component ship start` tracked it and built on the spec's old commits: the build PR conflicted with `main` on `spec.md` (the #410 fix only covered a local branch that was left behind). The ship now drops a remote-tracking ref whose branch is gone on origin and starts the feature branch from `origin/main` when the checkout has nothing `main` lacks, in a component ship and in every repo of a system ship. Update the plugins (`/plugin marketplace update`).
