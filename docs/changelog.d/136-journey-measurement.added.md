**A journey run records the time of every stage, and the benchmark report compares journeys across versions (spec 136).** `cplat platform runs journey begin|stage|wait|pr|round|show|end` records one run of the demo journey (empty folder to dev, database and web UI, staging to prod) as a run record of kind `journey`: per stage of the [spec's table](../specs/136-the-whole-journey-fits-a-time-budget/spec.md) its wall clock, working time (wall clock minus the time spent waiting for a person), person-wait and external-wait minutes, budget, PRs and extra rounds with their cause, and the same for each part and the whole journey; parts are spans over overlapping stages, and a stage that never ran is `not run`. Every event takes `--at`, so a journey reconstructed afterwards is recorded the same way, and cplat's own waits for GitHub's rate limit count as external waits on their own. `cplat platform runs report --benchmarks` adds a journey table per platform version and coordinator model: the median working time and wall clock of the done runs side by side, the budget, the overrun, the median waits and PR count, and the previous version's medians, with the stages ranked by overrun; `--json` holds it under `journey` ([ADR-081](../adr/081-a-journey-is-measured-in-stages-of-working-time.md)).
