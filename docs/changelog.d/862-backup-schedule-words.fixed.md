**`cplat resource backup --schedule` takes `hourly`, `daily` and `weekly` (#862).** Only a five-field cron expression was accepted, so "back up daily" took a refused call and a retry with `"0 3 * * *"`. The words now map to fixed times in UTC: `hourly` = `0 * * * *`, `daily` = `0 3 * * *`, `weekly` = `0 3 * * 0` (Sunday). The preview shows the cron expression and `system.yaml` stores it.
