**A pull request that changes only `scripts/cplat/` no longer runs every template smoke in CI (#407).** `detect what changed` in `.github/workflows/ci.yml` turned all smoke jobs on for any change under `scripts/`, so a cplat-only PR waited for the service-java smoke (113–191 s) and missed spec 112's 120 s target. The smokes now start only for the repository scripts they depend on: `scripts/detect-shape.sh` and `scripts/sync-template-copies.py` (all smokes) and `scripts/test-plan.sh` (gitops-app); other changes under `scripts/` still run the cplat tests and the e2e scope rules, and a test fails when a smoke starts calling another repository script.
