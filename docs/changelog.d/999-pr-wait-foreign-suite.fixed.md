**`cplat pr wait` no longer waits an hour on a check suite of another app that never runs (#999).** Dependabot attaches a queued `.github/dependabot.yml` suite without check runs to a head commit; it never completes, so a PR with all CI green timed out unmerged. `pr wait` now waits only for the repo's own checks: a pending check that no Actions run backs, while the head shows a suite of another app with no check runs, is printed once as "not waited for". The rule that a `pull_request` run must exist on the head (#787) is unchanged.
