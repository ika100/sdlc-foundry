# Getting help

- **How do I ...? / Is this the right approach?** Ask in [Discussions](https://github.com/ika100/sdlc-foundry/discussions).
- **Something is broken or surprising.** (Issues are public: do not paste secrets, customer data or private code.) Run `/issue:report` in Claude Code (it collects versions and the error text and removes secrets), or [open an issue](https://github.com/ika100/sdlc-foundry/issues/new/choose).
- **First, try `/platform:doctor`.** It checks your tools, `gh` scopes, Docker, kube context and plugin versions, and prints a fix for each problem. A running Claude Code session keeps old plugin prompts: restart it after `claude plugin update`.
- **Documentation:** [User journey](docs/USER-JOURNEY.md), [How it works](docs/HOW-IT-WORKS.md), [Adopting an existing repo](docs/ADOPTING.md) (with troubleshooting).
- **Security problems:** see [SECURITY.md](SECURITY.md); do not post them publicly.

This is a volunteer-maintained project; responses are best effort.
